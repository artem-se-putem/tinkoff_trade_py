Формальное

ценная бумага (актив)
активы могут торговаться на разных биржах
Совокупность актива и торговой площадки (биржи) — это позиция.

Isin (International Security Identification Number) — международный идентификационный номер ценной бумаги. 12 символов, первые две - страна (US, RU), далее номер-id ценной бумаги.

Ticker  - идентификатор ценной бумаге на КОНКРЕТНОЙ БИРЖЕ, иначе - набор букв.

FIGI - устаревший идентификатор.

Торговый инструмент - ценная бумага (акции, облигации, фонды) на торговой площадке (бирже) в указанном режиме торгов
Режим торгов - биржевой (TQBR), внебиржевой (в выходные).




Техническое

использовать uuid (а, не фиги, тк фиги не тинькофф-фиги может не совпадать с глобальными фиги)

uid бренда — идентификатор компании;
asset_uid — идентификатор актива;
position_uid — идентификатор позиции;
instrument_uid — идентификатор торгового инструмента;
ticker — тикер;
class_code — класс-код (секция торгов, режим торгов).

instrument_id - можно формировать как ticker + '_' + class_code (`instrument_id = 'T_TQBR'`). Здесь - тикер 'Т' (Тинькоф что-то там), TQBR - режим торгов (Основной режим торгов акциями на Московской бирже)


Класс-код	Описание
TQBR	Основной режим торгов акциями на Московской бирже
TQOB	Основной режим торгов облигациями на Московской бирже
SPBRU	Основной режим торгов акциями и фондами на Санкт-Петербургской бирже
SPBFUT	Торговля фьючерсами на Московской бирже
SPBOPT	Торговля опционами на Московской бирже
TQTF	Основной режим торгов фондами на Московской бирже
CETS	Основной режим торгов валютой на Московской бирже
